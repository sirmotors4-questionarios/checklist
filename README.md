# Checklist de Saída — SIR Motors

Aplicação web para registo da inspecção de viaturas antes da saída.

## Funcionalidades

- Identificação do utilizador, motorista e viatura
- Quilometragem e nível de combustível
- Verificação geral, mecânica e dos pneus
- Resultado automático: APTO ou NÃO APTO
- Registo das anomalias identificadas
- Interface adaptada a telemóveis

A configuração da integração é mantida separadamente da publicação web.
